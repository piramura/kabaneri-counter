# カバネリ実戦ポイントカウンター

[カウンターを開く](https://piramura.github.io/kabaneri-counter/)

**パチスロ甲鉄城のカバネリ（2022年・6.5号機・メダル機）の通常時専用カウンターです。**

無名・生駒・美馬のチャンス目や発光、高確、CZ/STを記録し、観測情報から判断できる最低減算ポイントを表示します。スマートフォンから利用でき、ログインは不要です。スマスロ「海門決戦」は対象外です。

## できること

- キャラ別の単独チャンス目・発光/非発光を1タップで記録
- 3キャラ独立の高確管理、複合チャンス目・オールスター目の記録
- 現在区間の最低減算ポイントと通常単独チャンス目の発光率を表示
- CZ区間・ST当選・実戦全体の履歴保存
- 複数回のUndo、ブラウザへの自動保存
- JSONによるバックアップ・復元、分析用CSVの出力

## 使い方

1. 単独チャンス目が成立したら、対応キャラの「発光」または「非発光」をタップします。
2. 対応キャラに「好機の帯」が出たら高確をON、終了したらOFFにします。複数キャラを同時にONにできます。
3. 複合目は組合せを選んで記録します。発光の有無を確認できていない場合は「未確認」のまま保存できます。
4. CZを観測したら、そのキャラのCZボタンで区間を保存します。他キャラのポイントは継続します。
5. ST当選時は「ST当選 / 通常時終了」で区間を保存・初期化します。次のチャンス目入力はST終了後の通常時に行ってください。
6. 誤入力は画面下部のUndoで取り消せます。
7. 実戦終了後は「実戦履歴」から過去の記録を閲覧できます。次回は新規実戦を開始します。

**表示ポイントは現在区間、メイン画面の発光率は実戦累計の非高確・単独チャンス目を対象にしています。**

## ポイントの読み方

表示するのは、入力した観測から判断できる**最低減算ポイントの合計**です。内部の残りポイントや、CZまでに必要なポイント数ではありません。

| 観測 | 記録する下限 |
| --- | --- |
| 非高確の単独・非発光 | 1pt |
| 非高確の単独・発光、CZ帰属未確認 | 1pt・確認待ち |
| 上記の発光がCZ非当選と確認できた場合 | 履歴から15ptに更新 |
| 対応高確の単独 | 発光にかかわらず15pt |
| 複合 | 各キャラ通常15pt・対応高確30pt |
| オールスター・無名/生駒 | 通常30pt・対応高確60pt |
| オールスター・美馬 | 減算量不明、CZ確定の事実を別記録 |

通常単独の発光は「15pt以上減算」だけでなく「CZ到達」でも起きます。そのため、非高確の発光はまず1ptとして記録します。前兆確認後、その成立ではCZ非当選と確認できた場合だけ、入力履歴の「確認」から15ptへ更新してください。確認結果を入力すると、保存済みCZ区間も再計算されます。

オールスターの美馬減算量は解析媒体の説明に差があるため、確定値として加算しません。「減算量不明」は実際の減算が0ptという意味ではありません。

解析の根拠・出典は [解析ルール](docs/analysis-rules.md) にまとめています。

## 保存・バックアップ

実戦データは**使用中のブラウザに自動保存**します。サーバーへ実戦データを送信する機能や、端末間の自動同期はありません。

- 「実戦履歴」からJSONを書き出すと、入力・確認・取消を含むデータをバックアップできます。
- 端末・ブラウザ・公開先ドメインを変える場合は、元の画面でJSON出力し、移行先でJSON復元してください。
- JSON復元は現在の保存データを置き換えます。
- CSVは分析用です。CSVからの復元には対応していません。
- ブラウザデータを削除すると実戦データも消えます。

## 利用上の注意

- 通常時専用です。CZ中・ST中・ボーナス中のチャンス目は入力対象外です。
- 高確は「好機の帯」を指します。ランプの点灯やチャンス目確率上昇状態とは別です。高確は自動OFFになりません。
- CZボタンによる区切りは記録した時点です。内部当選時点や、本前兆中の減算がどのCZに帰属するかを確定するものではありません。
- 発光率は観測した発光の割合であり、15pt以上の減算抽選率や設定の確率ではありません。
- 途中からの入力や入力漏れがある場合、その観測区間の記録として扱ってください。

HTML・CSS・JavaScriptで動作する静的Webアプリです。ポイント計算は画面処理と分離し、入力履歴から再計算します。設定推測・期待値計算は実装していません。メーカー公式のツールではありません。
